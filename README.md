# 🩸 Blood Bank Management System

A Python-based Blood Bank Management System with GUI support for managing donor, buyer, stock, and transaction records efficiently.

## 📌 Features

- 👤 Donor Management
  - Add donor details
  - View donor records
  - Generate donor reports

- 🛒 Buyer Management
  - Add buyer details
  - View buyer records
  - Generate buyer reports

- 🩸 Blood Stock Management
  - Maintain available blood stock
  - Update inventory records

- 🔄 Transaction Management
  - Record blood transactions
  - Maintain transaction history

- 📄 Report Generation
  - Print reports
  - Store transaction data

- 🔐 GUI-Based Interface
  - Simple and user-friendly graphical interface

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- File Handling / Database (depending on implementation)
